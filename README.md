# HOLDOUT

Persistent open-world survival with an action-horror feel: a collapsed desert city, parkour, skill-based melee and guns, base building, and the infected.
Browser prototype (three.js) — the place where movement, combat and systems get designed before the final Roblox build.

**Play:** https://reeksolutions.github.io/Holdout-game/  (Xbox controller recommended; keyboard works too)

Owners: reek (Marquise) & cousin. Assets: Quaternius (CC0), Mixamo, freesound — see `CREDITS.txt`.

## For AI helpers / developers
Start with **`AGENTS.md`** — code map, rules, and how to run the automated tests (`python3 tests/run_tests.py`).
Design doc: `docs/DESIGN.md`.

## Controls (controller)
Left stick move (full push = sprint) · Right stick look · A jump/vault/climb · B tap crouch, double-tap roll · X use · Y swap
RT attack / fire (hold = heavy) · LT aim / block (tap to parry) · LB flashlight · RB heal · D-pad map/build/eat/craft · View = backpack
